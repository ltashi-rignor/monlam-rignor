# Monlam Rignor — Tibetan Language Learning Platform

Agentic learning app: **React + Vite** frontend, **FastAPI** backend, **PostgreSQL / pgvector**, and **Monlam Melong** (plus optional Claude for grammar check).

## Prerequisites

- Python **3.12** + project `.venv`
- PostgreSQL with **pgvector**
- Node.js 20+
- `MONLAM_API_KEY` in `.env` (Monlam Studio X-API-Key)

## Local setup

```bash
# 1) Python 3.12 venv (already created at repo root)
source .venv/bin/activate
pip install -r backend/requirements.txt

# 2) Database (Homebrew example)
createdb monlam_rignor   # if needed
psql -d monlam_rignor -c 'CREATE EXTENSION IF NOT EXISTS vector;'

# 3) Configure
cp .env.example .env
# set MONLAM_API_KEY and a strong JWT_SECRET (≥32 chars)

# 4) Migrations (also run automatically on API boot)
cd backend && alembic upgrade head && cd ..

# 5) Ingest Classical Tibetan Grammar Handbook (page-wise, BGE-M3 embeddings)
export PYTHONPATH=backend
python backend/scripts/ingest_grammar.py

# 6) Run backend
cd backend && uvicorn app.main:app --reload --port 8000

# 7) Run frontend
cd frontend && npm install && npm run dev
```

- App: http://localhost:5173  
- API docs: http://localhost:8000/docs (local only; off when `APP_ENV=production`)  
- OTP codes print only when `OTP_DEV_LOG=true` (never in production)

## Docker Compose

```bash
# Local / demo stack (hot reload mounts, Mailpit)
docker compose up --build

# Production-shaped stack (no bind mounts / no reload)
docker compose -f docker-compose.prod.yml up --build -d
```

Includes PostgreSQL+pgvector, Mailpit (SMTP :1025, UI :8025), backend, frontend.

Prod compose sets `TRUST_PROXY_HEADERS=true` so rate limits can use `X-Forwarded-For` behind nginx.

## Architecture (high level)

| Layer | Role |
|-------|------|
| `frontend/` | React SPA — learn, practice, tutor, CMS marketing site |
| `backend/app/api/` | REST under `/api/*` |
| `backend/app/agents/` | Melong-backed agents (practice, grammar, planner, story, …) |
| `backend/app/rag/` | Handbook retrieval (pgvector + BGE-M3) |
| `backend/app/services/llm.py` | Shared Melong client + token usage logging |
| `backend/alembic/` | Schema migrations (incl. HNSW vector indexes) |

### Auth

1. Email OTP once to verify → set username/password  
2. Login issues **short-lived access JWT** + **rotating refresh token**  
3. Tokens are set as **httpOnly cookies** (`mr_access`, `mr_refresh`) — not stored in `localStorage`  
4. Browser calls use `credentials: 'include'`; `Authorization: Bearer` still accepted  
5. Refresh/logout can rely on the refresh cookie (body token optional)

### Security notes

| Setting | Meaning |
|---------|---------|
| `TRUST_PROXY_HEADERS` | Default `false`. Set `true` only behind a trusted reverse proxy. |
| Voice TTS/STT | Separate stricter rate limit (`rate_limit_voice`) |
| OTP | Stored hashed; unused prior codes invalidated; plaintext rejected |
| `/api/health/ready` | DB + Melong config status (no secret/JWT leakage) |
| Frontend nginx (prod) | CSP + standard security headers |

### Daily practice

- Generated by Melong from mistakes/profile, then **sanitized** in `practice_agent.py`
- Valid drills only: fill-blank, particle pick, honorific, correct sentence, match word, optional single-sentence reorder, at most one free-write
- Bad “number the paragraphs / options like `1, 2, 3, 4`” items are **dropped**
- Curated bank tops up to ~8 solid exercises when Melong returns junk
- Reorder (when valid) includes `tokens[]` chunks; UI shows them as chips
- Last question uses **Finish** (`མཇུག་སྒྲིལ།`); MC answers auto-advance

### Grammar & RAG

- Grammar check can use Melong or Claude (`GRAMMAR_LLM_PROVIDER`)
- Handbook excerpts are retrieved (pgvector) and passed into prompts
- Grammar Quest falls back to RAG/bank when Melong is rate-limited

### CMS marketing stats

- `/api/cms/stats` returns curriculum facts (letters, topics, AI tools)
- Verified learner count is bucketed and hidden when &lt; 10 (no vanity fiction)

## Frontend notes

- Vite proxies `/api` in dev → same-origin cookies work locally  
- i18n: `frontend/src/i18n/bo.js` + `en.js`  
- Trace stroke data (`tibetanTraceLetters.json`) is **lazy-loaded**  
- Offline / fallback Melong content surfaces via `OfflineBanner`
