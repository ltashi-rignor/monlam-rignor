04 · Features · Learn

Path, lessons & literacy

Dashboard & path

Skill overview from the database. Melong builds a week-by-week roadmap from the learner profile, with YAML available as fallback.

Interactive lessons

Staged flow: words → dialogue → quiz. Bank content for instant UX, Melong enrich on demand.

Alphabet & flashcards

Mastery journeys with Melong TTS — see, hear, match, unlock the next row or theme.

Handwriting

Canvas stroke tracing with tip lessons. Builds letter motor memory without an LLM call.

04 · Features · Practice & AI

Drills, games, tutor, story

Daily Practice

Melong drills from mistakes and profile. Sanitizer keeps items scorable. Can continue from grammar errors.

Letter Party

Falling-word vocabulary game. Melong theme packs with YAML fallback.

Grammar

Hybrid check: rules, RAG handbook, Melong/Claude. OCR homework. Grammar Quest play mode.

Tutor & Story

Profile-aware chat + live voice. Kid stories with glossary, quiz, and speak practice.

06 · Maintainability

Coding standards we keep

  • Small, typed Python modules with clear async boundaries
  • Validate and sanitize Melong JSON before UI scoring
  • Tibetan-first strings in i18n — keep learner copy out of hard-coded English
  • Document fallbacks and behavior in README / architecture notes
  • Add features by extending router + agent + page — without rewriting the core

Predictable folders make the codebase ready for new contributors and V2 work.
